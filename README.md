# openlfcp/examples

Small, understandable LFCP protocol examples and interoperability
demonstrations.

## Status

Repository scaffold only. No examples yet.

## Build from a clean checkout

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm test
```

Requires Node.js 24 or later and pnpm 10.
